# تمارين الويب — طريقة الشغل

## كل درس جديد

1. كليك يمين على مجلد `practice` → **New Folder** → سمّيه برقم واسم الدرس
   مثال: `07-css-basics`
2. انسخ ملفي `index.html` و `style.css` من مجلد **`_template`** والصقهم داخله
3. افتح `index.html` → كليك يمين → **Open with Live Server**
4. اكتب، احفظ (`Ctrl+S`)، والمتصفح يتحدث لحاله

## المجلدات الجاهزة

| المجلد | الموضوع |
|---|---|
| `_template` | قالب فارغ — انسخه لكل درس جديد |
| `01-html-basics` | الوسوم الأساسية، العناوين، الفقرات |
| `02-text-and-lists` | تنسيق النص، القوائم المرتبة وغير المرتبة |
| `03-images-and-links` | الصور، الروابط، المسارات |
| `04-tables` | الجداول |
| `05-forms` | الفورم والـ inputs |
| `06-semantic-and-media` | الوسوم الدلالية، الصوت والفيديو، iframe |

## قواعد تخليك مرتب

- اسم الصفحة الرئيسية **دائماً** `index.html`
- الصور حطها بمجلد `images` داخل مجلد الدرس، والمسار يصير `images/pic.jpg`
- **لا تستعمل مسارات كاملة** مثل `C:\Users\MSI\...` — هذي تشتغل عندك بس وتنكسر بأي جهاز ثاني أو لمن ترفع على GitHub
- كل ما تخلص درس، احفظ وارفع على GitHub بنفس اليوم
